      설정과 진단

      게이트웨이 Wi-Fi 연결

      게이트웨이가 오프라인이면 2.4 GHz Wi-Fi 또는 휴대폰 핫스팟을 연결하세요. 5 GHz 전용 Wi-Fi는 지원하지 않습니다.

      1. 휴대폰에서 SmartWardrobe-Setup Wi-Fi에 연결합니다.
      2. 아래 설정 페이지에서 Wi-Fi와 서버 주소를 직접 입력합니다.
      3. 연결 뒤 이 대시보드로 돌아오면 실시간 태그 상태가 표시됩니다.
