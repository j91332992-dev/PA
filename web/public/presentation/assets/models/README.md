# Presentation 3D models

Place presentation-ready `.glb` or `.gltf` assets in this folder.

Suggested names:

- `smart-hanger.glb`
- `pn532-board.glb`
- `hanger-hook-pogo.glb`

Current local model:

- `seeed-studio-xiao-esp32c6-v2.step` — original STEP supplied for the presentation
- `seeed-studio-xiao-esp32c6-v2.glb` — browser-ready conversion of that STEP file
- `nfc-pn532-reader.stp` — PN532 reader STEP supplied for the presentation
- `nfc-pn532-reader.glb` — browser-ready conversion of the PN532 STEP file
- `smart-hanger-reference.igs` — hanger reference IGS supplied for the presentation
- `smart-hanger-reference.glb` — browser-ready conversion of the hanger IGS file
